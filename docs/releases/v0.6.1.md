# v0.6.1 — the knowledge-graph release

Four features landed in parallel branches and merged into one release.

### Highlights

- **Knowledge graph** — `loci graph build` extracts entity–relation triples from your memories and wiki pages into a single human-readable `graph.json` (no graph database, hand-editable). Every edge cites its source file. Query with `loci graph show ENTITY` or the new `brain_graph` MCP tool (omit the entity to list hub entities). Wiki generation injects related graph relations as extra context.
- **OCR** (`[ocr]` extra, rapidocr) — image files are recognised and indexed; scanned PDFs (near-empty text layer) automatically fall back to per-page OCR. `loci doctor` reports availability.
- **HTML loader** (stdlib, zero deps) — headings, lists, `<meta charset>` with a gb18030 fallback for legacy Chinese exports.
- **org-mode loader** (stdlib, zero deps) — `#+TITLE` becomes the h1, `#+FILETAGS` become frontmatter tags, org links become markdown links.

MCP tool count: **9** (`brain_graph` joins). 173 offline tests, CI on 3.11–3.13.

### Install

```bash
pip install "loci-rag[pdf,docx,ocr]"
```

# v0.6.1 —— 知识图谱版本

四个特性在并行分支上开发，合并为一次发布。

### 亮点

- **知识图谱**——`loci graph build` 从记忆与 wiki 页面中抽取实体-关系三元组，写成单个人工可读、可直接手改的 `graph.json`（不用图数据库）。每条边都标注来源文件。用 `loci graph show ENTITY` 或新增的 `brain_graph` MCP 工具查询（省略实体则列出枢纽实体）。wiki 生成会把相关图谱关系作为额外上下文注入。
- **OCR**（`[ocr]` 可选依赖，rapidocr）——图片文件被识别并索引；扫描版 PDF（文本层几乎为空）自动回退到逐页 OCR。`loci doctor` 会报告可用性。
- **HTML 加载器**（标准库，零依赖）——支持标题、列表、`<meta charset>`，并为旧版中文导出提供 gb18030 回退。
- **org-mode 加载器**（标准库，零依赖）——`#+TITLE` 变成一级标题，`#+FILETAGS` 变成 frontmatter 标签，org 链接转为 markdown 链接。

MCP 工具数：**9**（新增 `brain_graph`）。173 项离线测试，CI 覆盖 3.11–3.13。

### 安装

```bash
pip install "loci-rag[pdf,docx,ocr]"
```
