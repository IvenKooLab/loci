## Changelog

Query understanding, memory automation and efficiency across the board.

### Highlights

- **Query rewriting** — `loci ask --rewrite` generates keyword and cross-language variants of your query, retrieves per variant and RRF-fuses the results. A Chinese query can now surface the English document it used to miss.
- **Automatic memory extraction** — `loci chat` distils durable facts from each exchange into memory notes automatically (mem0 pattern, at most 3 per exchange, fail-open). Your agent remembers without being asked.
- **Chunk-level incremental indexing** — only changed chunks are re-embedded; unchanged vectors are reused through content fingerprints. Editing one paragraph no longer re-embeds the whole file.
- **Feedback loop** — `loci feedback good|bad` rates the chunks behind the last answer; badly rated chunks sink in future retrieval.
- **HTTP REST API** — `loci serve-http` exposes search / ask / remember / stats over JSON with Bearer auth, for non-MCP tools (shortcuts, automations, home servers).
- **Git memory sync** — `loci sync push|pull` version-controls the memories/ and wiki/ directories for cross-machine memory sharing. No cloud, no accounts.
- **Wiki topic suggestions** — `loci wiki --suggest` recommends topics that have enough indexed material but no wiki page yet.
- **`loci bench`** — a built-in retrieval benchmark (hit@k, vector-only vs hybrid) over your own labelled queries.

### Fixes

- Python 3.11 compatibility (an f-string syntax from PEP 701 was 3.12-only).
- Feedback penalties are now actually applied in retrieval (a dead-code bug caught by tests).
- Config warnings go to stderr, so MCP stdio streams stay clean.

### Install

```bash
pip install "loci-rag[pdf,docx]"
```

## 更新日志

查询理解、记忆自动化与整体效率提升。

### 亮点

- **查询改写**——`loci ask --rewrite` 为查询生成关键词变体与跨语言变体，分别检索后用 RRF 融合。中文提问现在能命中以前漏掉的英文文档。
- **自动记忆抽取**——`loci chat` 自动从每轮对话中提炼持久事实写成记忆笔记（mem0 模式，每轮最多 3 条，失败不影响对话）。代理不用被要求也会记住。
- **分块级增量索引**——只重新嵌入变化的分块，未变的向量按内容指纹复用。改一个段落不再重嵌整个文件。
- **反馈回路**——`loci feedback good|bad` 给上次回答背后的分块打分；差评分块在后续检索中下沉。
- **HTTP REST API**——`loci serve-http` 以 JSON + Bearer 鉴权提供 search / ask / remember / stats，方便非 MCP 工具（快捷指令、自动化、家庭服务器）调用。
- **Git 记忆同步**——`loci sync push|pull` 把 memories/ 与 wiki/ 纳入版本控制，实现跨机器共享记忆。不用云，不要账号。
- **Wiki 主题建议**——`loci wiki --suggest` 推荐那些索引材料够多但还没有 wiki 页面的主题。
- **`loci bench`**——内置检索基准（hit@k，纯向量 vs 混合），跑在你自己的标注查询上。

### 修复

- Python 3.11 兼容性（PEP 701 的 f-string 语法只在 3.12 可用）。
- 反馈惩罚现在真正作用于检索（死代码 bug，被测试发现）。
- 配置警告输出到 stderr，保持 MCP stdio 通道干净。

pip install "loci-rag[pdf,docx]"
