## Changelog

loci turns scattered notes, project docs and chat logs into a queryable second brain: a local index, hybrid retrieval, cited answers, and an MCP server so your AI agents can use it. The core is about 300 lines of plain Python — no LangChain, no Docker, no daemons.

### Highlights

- **Hybrid retrieval by default** — native BM25 (CJK-aware) fused with vector search through Reciprocal Rank Fusion. On a bilingual corpus: 9/10 → 10/10 hit@5 compared with vector-only.
- **MCP server with zero extra dependencies** — `brain_search` / `brain_ask` / `brain_links` / `brain_stats` / `brain_ingest` over stdio, plus **resources** (`brain://note/…`, `brain://stats`) and three **prompts** (brain-briefing / study-plan / contradiction-check).
- **Verified fully offline** — point both endpoints at a local Ollama and the whole pipeline runs with zero cloud calls.
- **Section-level citations** — every answer and hit carries `file > heading` breadcrumbs; the optional **`ask --verify`** audits an answer claim by claim against the sources (✓ / ~ / ✗).
- **Reranking with two providers** — LLM pointwise scoring, or a local cross-encoder (`BAAI/bge-reranker-base`, roughly 30–70 ms for 5 pairs on GPU) through an optional extra.
- **Obsidian-native details** — frontmatter tags (`--tag`), the `[[wikilink]]` graph (`links`), fenced code blocks are never split, one-line notes stay searchable.
- **Office & PDF** — PyMuPDF4LLM extracts PDFs as markdown with tables as pipe rows; `.docx` paragraphs and tables via an optional extra.
- **Chat-log loader** — ChatGPT / Claude `conversations.json` exports become one searchable document per conversation.
- **Per-directory chunk config** — `[[sources]]` entries override `chunk_size` / `chunk_overlap`.
- **Quality signals** — 115 offline tests (no API keys needed), GitHub Actions CI (3.11–3.13 plus a packaging smoke test), a built-in retrieval eval harness, `stats` / `doctor` / `watch` / `chat` commands.

### Quick start

```bash
pip install -e ".[pdf,docx]"
cp config.example.toml config.toml   # add your API key + source dirs
second-brain ingest
second-brain ask "what did I write about X?"
```

## 更新日志

loci 把散落的笔记、项目文档和聊天记录变成可查询的第二大脑：本地索引、混合检索、带引用的回答，以及让 AI 代理直接可用的 MCP 服务。核心约 300 行纯 Python——不用 LangChain，不用 Docker，没有常驻守护进程。

### 亮点

- **默认混合检索**——原生 BM25（支持中日韩分词）与向量检索经 RRF 融合。在双语语料上，hit@5 从纯向量的 9/10 提升到 10/10。
- **零额外依赖的 MCP 服务**——stdio 上提供 `brain_search` / `brain_ask` / `brain_links` / `brain_stats` / `brain_ingest`，另有 **resources**（`brain://note/…`、`brain://stats`）与三个 **prompts**（brain-briefing / study-plan / contradiction-check）。
- **实测可完全离线**——两个端都指向本地 Ollama 时，整条流水线零云端调用。
- **段落级引用**——每条回答与命中都带 `file > heading` 面包屑；可选 **`ask --verify`** 逐条核对回答与来源（✓ / ~ / ✗）。
- **两种重排**——LLM 打分，或通过可选依赖使用本地 cross-encoder（`BAAI/bge-reranker-base`，GPU 上 5 对约 30–70 ms）。
- **Obsidian 原生细节**——frontmatter 标签（`--tag`）、`[[wikilink]]` 图谱（`links`）、围栏代码块不被切断、单行笔记也能检索。
- **Office 与 PDF**——PyMuPDF4LLM 把 PDF 抽成 markdown（表格转管道行）；`.docx` 段落与表格经可选依赖支持。
- **聊天记录加载器**——ChatGPT / Claude 的 `conversations.json` 导出，每个会话变成一篇可检索文档。
- **按目录配置分块**——`[[sources]]` 可覆盖 `chunk_size` / `chunk_overlap`。
- **质量信号**——115 项离线测试（无需 API key）、GitHub Actions CI（3.11–3.13 及打包冒烟）、内置检索评测工具，以及 `stats` / `doctor` / `watch` / `chat` 命令。
