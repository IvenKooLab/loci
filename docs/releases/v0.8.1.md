# loci v0.8.1 — 管理台、共享记忆与稳定性更新

本次发布汇总 v0.6.3 之后的功能更新，并包含最新 HTTP 修复与五语言文档重构。

## 新功能

- **内置 Web 管理台**：运行 `loci serve-http`，打开 `http://127.0.0.1:8765/ui`，即可搜索、问答、浏览和编辑共享记忆、更新索引及查看审计。支持中英文、深浅色切换。
- **Harness 记忆中枢**：自动发现支持的 AI 编码工具，查看各工具的文件、索引和摘要状态；可按内容变化增量生成摘要。
- **角色权限与审计**：viewer / editor / admin 多 token 权限。本机回环匿名连接默认拥有管理员权限；经反向代理或 SSH 隧道访问时请设置 `[http] local_admin = false`。
- **统一实例目录**：`LOCI_HOME` 将配置、索引、记忆与 wiki 锚定到同一目录，便于 MCP、服务管理器及多个 AI 工具共享实例。

## 修复

- 严格检查文件目录边界，阻止同名前缀目录及越界符号链接被错误放行。
- 后端写入与管理操作失败时返回 JSON 错误，避免请求连接直接断开。
- 拒绝非法或非对象 JSON、无效 Content-Length 与超过 1 MiB 的 POST 请求体。
- 修复来源文件路径的重复 URL 解码问题。

## 文档

- 统一重构 English、简体中文、繁體中文、日本語、한국어五种 README。
- 新增真实管理台的浅色、深色截图，全部使用隔离的虚构数据，不连接个人知识库或密钥。
- 新增可复现的只读演示脚本与独立使用指南。

## 安装与升级

从本 Release 下载 wheel 后安装（仍需 Python 3.11+ 及运行依赖）：

```bash
python -m pip install --upgrade ./loci_rag-0.8.1-py3-none-any.whl
```

首次使用请从完整源码 ZIP 或源码发行包取得 `config.example.toml`，复制为实例目录中的 `config.toml`，填写模型与文档目录，然后执行 `loci ingest`。升级后重启 loci HTTP / MCP 服务以加载新代码。仅在更换向量模型时执行 `loci ingest --force`。

- `.whl`：跨平台 Python 安装包。
- `.tar.gz`：Python 源码发行包（sdist）。
- `loci-0.8.1-source.zip`：完整仓库源码，包含文档、截图和示例脚本。
- `SHA256SUMS`：以上三个文件的 SHA-256 校验值。

本次为代码托管平台 Release，附件可直接安装；不表示已发布到 PyPI。

## English summary

This release rolls up the changes since v0.6.3: a built-in Web console,
automatic harness memory discovery and summaries, role-based tokens and audit,
and `LOCI_HOME` for shared instances. It also fixes HTTP path containment,
backend error responses, malformed/oversized request handling and double URL
decoding. All five README editions now share a consistent layout and include
console screenshots backed exclusively by fictional fixtures.

Install the attached wheel with Python 3.11+, then restart your HTTP/MCP
services. Use the complete source ZIP for documentation and configuration
examples. Hosted models still receive the embedding/chat requests configured
in your instance. For proxies or SSH tunnels, disable anonymous loopback admin
with `[http] local_admin = false` and configure role tokens.

Full change history: [CHANGELOG](https://github.com/IvenKooLab/loci/blob/v0.8.1/CHANGELOG.md).
