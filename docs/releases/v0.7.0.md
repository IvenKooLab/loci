# v0.7.0 — provider neutralization

**Breaking change**: default endpoints now follow the **OpenAI standard** — any OpenAI-compatible provider works out of the box without custom base URLs.

### Added

- `LOCI_HOME` instance anchoring — isolate data, config and cache per deployment.
- Real-world deployment scenario docs.

### Fixed

- Long-running service self-healing (serve-http resilience).
- Embedding vector-space guard (dimension mismatches caught early).
- docx degradation rescue for malformed files.
- Windows test compatibility (TOML path escaping).

### Packaging

- The sdist now ships CHANGELOG.md and config.example.toml.

Install: `pip install loci-rag==0.7.0`

# v0.7.0 —— 服务商中立化

**破坏性变更**：默认端点改为遵循 **OpenAI 标准**——任何 OpenAI 兼容的服务商开箱即用，无需自定义 base URL。

### 新增

- `LOCI_HOME` 实例锚定——按部署隔离数据、配置与缓存。
- 真实部署场景文档。

### 修复

- 长跑服务自愈（serve-http 韧性）。
- 嵌入向量空间守卫（维度不匹配及早发现）。
- 畸形 docx 文件的降级抢救。
- Windows 测试兼容性（TOML 路径转义）。

### 打包

- sdist 现在包含 CHANGELOG.md 与 config.example.toml。

安装：`pip install loci-rag==0.7.0`
