# v0.6.2 — integration-hardening release

Fixes found by the first downstream integration ([loci-dsh](https://github.com/IvenKooLab/loci-dsh), a visual plugin for DeepSeek Harness).

### Fixes

- **The `serve-http`, `sync` and `bench` CLI subcommands are now actually registered** (the dispatch existed but the argument-parser entries were missing).
- **HTTP API robustness**: handler exceptions return a 500 JSON body instead of dropping the connection (an empty query used to kill it), malformed bodies return 400, and empty queries short-circuit with a hint.
- `--host` / `--port` default from the `[http]` configuration section as documented.

Read the new **Ecosystem** section in the README for the loci-dsh integration story.

# v0.6.2 —— 集成加固版本

由第一个下游集成（[loci-dsh](https://github.com/IvenKooLab/loci-dsh)，DeepSeek Harness 的可视化插件）发现并修复的问题。

### 修复

- **`serve-http`、`sync`、`bench` 三个 CLI 子命令现在真正注册了**（分发逻辑一直在，但参数解析器条目缺失）。
- **HTTP API 健壮性**：处理异常返回 500 JSON 而不是直接断开连接（以前一个空查询就能把连接打断），畸形请求体返回 400，空查询快速短路并给出提示。
- `--host` / `--port` 按文档所述从 `[http]` 配置段取默认值。

README 新增 **Ecosystem** 一节，讲述 loci-dsh 的集成故事。
